🔬 Validation Tests Implemented

1. Fold Uniformity

Threshold: ≥ 85% efficiency

Compares actual fold distribution against nominal fold to ensure uniform coverage across the survey.

2. Offset Distribution

Threshold: ≥ 90% coverage

Validates that offset vector distribution provides adequate subsurface illumination.

3. Azimuth Coverage

Threshold: ≥ 75% range

Checks receiver and source line azimuth ranges for adequate directional coverage.

4. CDP Spacing

Validates CDP bin grid configuration and spacing parameters.

5. Line Parameters

Verifies receiver and source line setup, channel counts, and intervals.

6. Offset Balance

Ensures balance between inline and crossline offset coverage.

🚀 Quick Start Guide

Step 1: Install Dependencies

pip install -r requirements.txt

Step 2: Run Example

python example_mesa_validation.py

Step 3: Use in Your Code

from seismic_feasibility_model import (
    AcquisitionGeometry,
    MESAValidator,
    StatisticsCalculator,
    ReportGenerator,
    PlotGenerator
)

# Define geometry
geometry = AcquisitionGeometry(...)

# Run validation
validator = MESAValidator(geometry)
results = validator.validate_all()

# Calculate statistics
calculator = StatisticsCalculator(geometry)
stats = calculator.calculate_all()

# Generate reports
reporter = ReportGenerator(geometry, validator, calculator)
reporter.generate_text_report('report.txt')
reporter.generate_html_report('report.html')

# Create visualizations
plotter = PlotGenerator(geometry, stats)
plotter.generate_all_plots('.')
